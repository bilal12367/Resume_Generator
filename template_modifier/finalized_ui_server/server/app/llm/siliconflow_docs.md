# SiliconFlow LLM (LlamaIndex) Quick Reference Guide

Documentation and code usage patterns for `llama_index.llms.siliconflow.SiliconFlow` covering initialization, text completion, chat completion, streaming, response formatting (structured output), and tool/function calling.

---

## 1. Initialization

```python
import os
from llama_index.llms.siliconflow import SiliconFlow

llm = SiliconFlow(
    model="Qwen/Qwen2.5-72B-Instruct",      # SiliconFlow model ID
    api_key=os.getenv("SILICONFLOW_API_KEY"), # Or pass string directly
    base_url="https://api.siliconflow.cn/v1", # Optional custom base URL
    temperature=0.7,
    max_tokens=4096,
    timeout=120.0
)
```

---

## 2. Text Completion (`complete` / `acomplete`)

Generate a single response from a string prompt.

### Synchronous:
```python
response = llm.complete("Explain quantum computing in two sentences.")
print(response.text)
```

### Asynchronous:
```python
response = await llm.acomplete("Explain quantum computing in two sentences.")
print(response.text)
```

---

## 3. Chat Completion (`chat` / `achat`)

Pass conversation history using `ChatMessage` objects (`MessageRole.SYSTEM`, `USER`, `ASSISTANT`).

```python
from llama_index.core.llms import ChatMessage, MessageRole

messages = [
    ChatMessage(role=MessageRole.SYSTEM, content="You are a concise python assistant."),
    ChatMessage(role=MessageRole.USER, content="How do I read a JSON file in Python?"),
]

# Synchronous:
response = llm.chat(messages)
print(response.message.content)

# Asynchronous:
response = await llm.achat(messages)
print(response.message.content)
```

---

## 4. Streaming (`stream_complete` / `stream_chat`)

Stream tokens incrementally as they are generated by the model.

### Stream Completion:
```python
# Sync stream
stream_response = llm.stream_complete("Write a poem about open-source software.")
for chunk in stream_response:
    print(chunk.delta, end="", flush=True)

# Async stream
async_stream = await llm.astream_complete("Write a poem about open-source software.")
async for chunk in async_stream:
    print(chunk.delta, end="", flush=True)
```

### Stream Chat:
```python
# Sync chat stream
chat_stream = llm.stream_chat(messages)
for chunk in chat_stream:
    print(chunk.delta, end="", flush=True)

# Async chat stream
async_chat_stream = await llm.astream_chat(messages)
async for chunk in async_chat_stream:
    print(chunk.delta, end="", flush=True)
```

## 5. Response Formatting (Structured Output via Pydantic)

To enforce structured JSON schema outputs from `SiliconFlow`, use LlamaIndex's `structured_predict` or `asstructured_predict` with a Pydantic model:

```python
from pydantic import BaseModel, Field

class UserProfile(BaseModel):
    name: str = Field(description="Full name of candidate")
    years_experience: int = Field(description="Total years of experience")
    skills: list[str] = Field(description="List of primary technical skills")

# Synchronous Structured Output:
profile: UserProfile = llm.structured_predict(
    UserProfile,
    prompt="Extract candidate info: Bilal is a Software Engineer with 5 years of experience in Python, FastAPI, and Docker."
)
print(profile.name)             # 'Bilal'
print(profile.years_experience) # 5
print(profile.skills)           # ['Python', 'FastAPI', 'Docker']

# Asynchronous Structured Output:
profile: UserProfile = await llm.asstructured_predict(
    UserProfile,
    prompt="Extract candidate info: Bilal is a Software Engineer with 5 years of experience in Python, FastAPI, and Docker."
)
```

*Note: You can also pass custom raw JSON schema parameters directly using `additional_kwargs`:*
```python
response = await llm.acomplete(
    prompt="Return a json with name and age for John who is 30.",
    additional_kwargs={"response_format": {"type": "json_object"}}
)
```

## 6. Tool / Function Calling (`predict_and_call` / `apredict_and_call`)

`SiliconFlow` inherits from LlamaIndex `FunctionCallingLLM` and supports executing tools via `FunctionTool`:

```python
from llama_index.core.tools import FunctionTool

# Define custom tools
def multiply(a: float, b: float) -> float:
    """Multiplies two numbers and returns the product."""
    return a * b

def add(a: float, b: float) -> float:
    """Adds two numbers and returns the sum."""
    return a + b

tools = [
    FunctionTool.from_defaults(fn=multiply),
    FunctionTool.from_defaults(fn=add)
]

# Synchronous Tool Execution:
tool_response = llm.predict_and_call(
    tools=tools,
    user_msg="What is 15 multiplied by 4?",
    verbose=True
)
print(tool_response.response) # Prints result after calling the tool

# Asynchronous Tool Execution:
tool_response = await llm.apredict_and_call(
    tools=tools,
    user_msg="What is 15 multiplied by 4?",
    verbose=True
)
print(tool_response.response)
```
